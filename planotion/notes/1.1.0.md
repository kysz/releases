Calendar and planning improvements.

- **Block personal events automatically.** Turn it on in **Settings › Planning** and upcoming personal events are blocked on your work calendar without a right-click. Events you unblock by hand stay unblocked.
- **Tasks in the same block share one card.** Each task gets its own row, which you can drag or open on its own. Rows that don't fit fold into a **+N** list.
- **Overlapping blocks stack like Calendar.** When a later block leaves the earlier one's title visible, it's drawn on top, indented, instead of squeezed into its own column.
- **Drag a project's Today heading onto the calendar** from Triage to block out time for it. Hold Shift to fill the block with the project's unscheduled Today tasks.
- **See where an unscheduled task went.** Dragging a block off the calendar now highlights the project it went back to in the sidebar.
- **A little celebration** when you tick off a task.

Fixes

- "Block time on" and "Block personal events on" now group calendars by account, so two calendars with the same name can be told apart.
- A sub-task's link icon in a block's popup highlights on hover and no longer also opens the sub-task.
- The outline around a dragged project heading is now evenly spaced.
